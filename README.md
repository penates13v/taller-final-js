# Star Wars Character Explorer 🚀

Este proyecto es una aplicación web interactiva que consume datos de la **API pública de Star Wars (SWAPI)**. Permite a los usuarios buscar y visualizar información técnica de los personajes de la saga de forma dinámica.

## 🛠️ Tecnologías Utilizadas
- **HTML5**: Estructura semántica para una mejor accesibilidad.
- **CSS3**: Diseño moderno con **CSS Grid** y **Flexbox**, incluyendo diseño **Responsive** para móviles.
- **JavaScript (ES6+)**: Consumo de API, manejo de asincronía y manipulación del DOM.
- **Git & GitHub**: Control de versiones con un flujo de trabajo organizado.

## 🌟 Funcionalidades Principales
- **Consumo de API Real**: Conexión con `swapi.dev` mediante `fetch` y `async/await`.
- **Buscador Galáctico (Reto Extra)**: Permite filtrar personajes por nombre en tiempo real.
- **Interfaz Adaptable**: El sitio se ajusta automáticamente a pantallas de celulares, tablets y computadoras.
- **Feedback de Usuario**: Mensajes de carga ("Buscando...") y manejo de errores si la búsqueda no arroja resultados.
