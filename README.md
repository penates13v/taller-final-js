# PokéDex Online - Taller Final JS 🚀

Este proyecto es una aplicación web interactiva que consume datos de la **PokeAPI**. Permite a los usuarios explorar una lista de Pokémon y realizar búsquedas específicas por nombre para obtener detalles visuales y técnicos.

## 🛠️ Tecnologías Utilizadas
- **HTML5**: Estructura semántica (Header, Main, Footer).
- **CSS3**: Diseño moderno con **CSS Grid**, **Flexbox** y **Media Queries** para que sea totalmente responsive.
- **JavaScript (ES6+)**: Consumo de APIs mediante `fetch`, manejo de asincronía con `async/await` y manipulación dinámica del DOM.
- **Git & GitHub**: Control de versiones y despliegue.

## 🌟 Funcionalidades Principales
- **Consumo de API Real**: Conexión con `pokeapi.co` para obtener datos actualizados.
- **Buscador Dinámico (Reto Final)**: Filtra Pokémon por nombre en tiempo real.
- **Interfaz Adaptable**: Diseño optimizado para dispositivos móviles y escritorio.
- **Gestión de Estados**: Mensajes de carga ("Buscando...") y manejo de errores (Try/Catch) para una mejor experiencia de usuario.
